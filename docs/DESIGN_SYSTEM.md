# SOLEFORM design

Warm ivory surfaces (`#f8f7f2`), charcoal text (`#20251f`), and lime accents (`#d5f46a`). Manrope headings, DM Sans body text and italic Georgia accents.

The footwear experience uses a sneaker hero, style edits, image-first product cards, department tabs, an editorial preloved feature, and quick size discovery. Desktop filters sit beside the catalog; mobile filters open in a drawer. Reduced-motion preferences disable decorative animation.

Shared shoe components are in `src/components/shoe`, storefront additions in `src/pages/shoe`, and the design overrides in `src/styles/shoe.css`. Legacy workflow styles remain where customer/admin screens use them.
